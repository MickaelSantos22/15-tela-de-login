# 🔐 Login Form

Projeto de desenvolvimento Front-End de uma interface de login com design minimalista, utilizando cores sólidas, campos personalizados e elementos centralizados.

O objetivo é praticar HTML5 e CSS3 na construção de formulários responsivos.

## 🖥️ Demonstração

https://mickaelsantos22.github.io/15-tela-de-login

## ✨ Funcionalidades

- Formulário de login.
- Campo de e-mail com validação básica do navegador.
- Campo de senha.
- Opção "Lembrar-me".
- Link para recuperação de senha.
- Efeitos de interação nos campos e botão.
- Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📂 Estrutura do projeto

```text
login-form/
│
├── index.html
└── style.css
```

## 📚 Conceitos praticados

- Estruturação semântica com HTML.
- Formulários e campos de entrada.
- Flexbox.
- Box Model.
- Centralização de elementos.
- Box Shadow.
- Border Radius.
- Pseudo-classes (`:focus`, `:hover` e `:active`).
- Transições com CSS.
- Media Queries.
- Design responsivo.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento Front-End, com foco na prática de HTML e CSS e no desenvolvimento de interfaces modernas e responsivas.

## ⚠️ Observação

Esta é uma interface demonstrativa para fins de estudo. Não possui autenticação real, Back-End ou armazenamento de dados.
